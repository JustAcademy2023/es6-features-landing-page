# JavaScript ES6 Features Every Developer Must Know: Interactive Landing Page

A bold yellow and black landing page that teaches modern JavaScript by letting you flip real code from ES5 to ES6 with a single switch. It also includes feature cards, a three question quiz, a saved learning path and a reading list.

Live page: after you enable GitHub Pages, it will be available at `https://YOUR-USERNAME.github.io/es6-features-landing-page/`

## What is inside

The page is one self contained file, so there is nothing to install or build.

**Playground.** Eight features (let and const, arrow functions, template literals, destructuring, spread, default and rest, classes, promises) shown as old and new code. A switch flips between the two and shows how many lines you save.

**Feature cards.** Eight cards with a short snippet and a "Show the catch" button that reveals the mistake people usually make with that feature.

**Quiz.** Three interview style puzzles with instant feedback and a final score.

**Learning path.** Seven ordered steps with checkboxes and a progress ring. Progress is stored in your browser with localStorage.

**Reading list and courses.** Blog and course links, all clickable and opening in a new tab.

## Run it locally

Open `index.html` in any browser. That is all.

## Publish with GitHub Pages

1. Create a new repository named `es6-features-landing-page` and upload `index.html` and this `README.md`.
2. Open the repository, go to Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the `main` branch and the `/ (root)` folder, then press Save.
5. Wait a minute or two and your page will go live at the address shown on that screen.

## Customise it

Colours live in the `:root` block at the top of the stylesheet (`--yellow`, `--ink`, `--paper`, `--gold`). Playground code samples are in the `F` array in the script, quiz questions are in `Q`, learning steps are in `S` and feature cards are in `C`. Edit those arrays and the page rebuilds itself.

## Built with

Plain HTML, CSS and JavaScript. Fonts are Bricolage Grotesque and JetBrains Mono from Google Fonts. The layout is responsive, keyboard friendly and respects the reduced motion setting.
